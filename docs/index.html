Install

Install via Homebrew or build from source.

Homebrew (macOS / Linux)

brew install bpauli/tap/gccli

Build from source

git clone https://github.com/bpauli/gccli.git
cd gccli
make build
./bin/gccli --help

Shell Completions

# Bash (~/.bashrc)
source <(gccli completion bash)

# Zsh (~/.zshrc)
source <(gccli completion zsh)

# Fish (~/.config/fish/config.fish)
gccli completion fish | source

# PowerShell ($PROFILE)
gccli completion powershell | Invoke-Expression

Quickstart

Authenticate once via browser or headless, then start querying your Garmin data.

1

Log in via browser SSO

Opens your browser for Garmin SSO. Tokens are stored in your system keyring.

gccli auth login you@example.com
2

Or log in headless

For servers or CI. Supports MFA.

gccli auth login you@example.com --headless
gccli auth login you@example.com --headless --mfa-code 123456
3

Start using

Login saves your default account automatically. Check auth status and fetch your recent activities.

gccli auth status
gccli activities list --limit 5
🔑

Keyring backends

Defaults to auto-detect. Force with GCCLI_KEYRING_BACKEND: keychain (macOS), secret-service (Linux D-Bus), or file (fallback). The file backend encrypts tokens with a fixed passphrase that is built into gccli. Anyone who can read the files can decrypt the tokens. Use the keychain or Secret Service when you can.

Features

Comprehensive Garmin Connect coverage with consistent CLI patterns and clean output.

🏃

Activities

List, search, view details, splits, weather, HR/power zones. Download FIT/GPX/TCX/KML/CSV. Upload, create (with date), rename, retype, delete. Set exercise sets for strength training. List pending activities.

❤

Health Data

Steps, heart rate, sleep, stress, HRV, SpO2, respiration, body battery, floors, training readiness, VO2max, fitness age, race predictions, critical swim speed, power curve, running economy.

💪

Workouts

Create with pace/HR/power/cadence targets, schedule to calendar, download as FIT, upload from JSON, update in place without losing the ID or schedule. Running, cycling, strength, and more.

⚖

Body Composition

Weight tracking, body fat, muscle mass, weigh-in history, blood pressure. Add entries and upload via FIT encoding.

🗺

Courses

List courses, view favorites, get full course detail, download as FIT or GPX. Import GPX files as new courses. Send courses directly to your device or delete them.

⌚

Devices

List registered devices, view settings, solar data, alarms. Query primary and last-used device. List paired sensors and the backup summary.

👟

Gear

List gear, usage stats, linked activities, defaults per activity type. Link and unlink gear to activities. List gear types and gear collections.

🎯

Goals & Badges

Active goals, earned/available/in-progress badges, badge details, challenges, and personal records.

📅

Events

List, add, and delete calendar events, such as races and group rides. Set custom goals and training priority.

📅

Training Plans

Browse and view training plans from the Garmin training catalog. Show your active plans.

💧

Hydration

View and log daily water intake. Track hydration by date.

🍲

Nutrition

View daily food logs, meal summaries, and nutrition settings by date.

🌿

Wellness

Menstrual cycle tracking, menstrual summaries, pregnancy summary data, and jet lag trips.

👥

Social

Read your notifications. List your connections, the followers of a user, and your groups.

👤

Profile

View user profile information and account settings.

📏

Your Unit System

Tables show km or miles, pace per km or per mile, and elevation in metres or feet, as set in your Garmin Connect profile. Pin one with --units. JSON is never converted.

🔄

Resilient Networking

Retries 429 up to 3 times within Retry-After, retries 5xx up to 2 times for read requests with exponential backoff, fails a request when no data moves for 60 s (a transfer that keeps moving has no time limit), and refreshes OAuth2 tokens on 401.

⌨

Shell Completion

Generated completion scripts for bash, zsh, fish, and PowerShell. Commands, subcommands, flags, and enum values.

Setup

Clone the repo and point your agent at skills/gccli (copy or symlink it into wherever your agent discovers skills). Authenticate once with gccli auth login and set GCCLI_ACCOUNT. The skill instructs the agent to use --json output and to confirm before destructive actions.

Commands

Click a group to expand. Every command supports --json, --plain, and --help. Only some commands print TSV with --plain. Most others print JSON in all modes (see Global Flags below). Write commands print the Garmin response with --json, or {"ok": true} when the response is empty. Without --json they print a message on stderr and nothing on stdout. Only courses import prints a table on stdout instead (TSV with --plain). On every paginated command --limit must be at least 1 and --offset must not be negative. In events list, --offset must be 0 or a multiple of --limit.

Export credentials for transfer to another machine.
gccli auth import [<token>]
Import credentials from another machine.
[<token>] Base64-encoded token string from 'auth export'. Reads from stdin if omitted.

Global Flags

FlagDescription
--account <email>Account to use (overrides GCCLI_ACCOUNT and config default)
--json, -jOutput JSON to stdout. Write commands print the Garmin response, or {"ok": true} when the response is empty. Runtime errors go to stderr as {"error":{"code":"...","status":404,"message":"..."}}
--plainOutput TSV to stdout, with no header row unless you add --header. Table and TSV output escape a backslash as \\, a tab as \t, a newline as \n, a carriage return as \r, a vertical tab as \v and a form feed as \f, so each record is one line. Only these commands print TSV: activities list, activities search, activities types, activity summary, courses list, courses favorites, courses import, events list, workouts list, workouts schedule list and exercises list (without --category). Most other commands print JSON in all modes.
--headerWith --plain, print the column names as the first line. activity summary has no column names. Without --plain, or with --json, it is a usage error (exit code 2). GCCLI_HEADER is not an error: table and JSON output ignore it.
--color <mode>Color mode: auto, always, never
--units <system>Unit system for table and plain output: auto (default, from the Garmin profile), metric (km, m), statute_us (mi, ft), statute_uk (mi, m). Precedence: flag, GCCLI_UNITS, config "units", Garmin profile, metric. Pin it for scripts that parse --plain.
--versionPrint version information
--helpShow help for any command

Examples

Real-world scripts and one-liners you'll use daily.

Export all runs from the last month

Fetch running activities and download each as GPX.

gccli --json activities search \
  --start 2024-05-15 --end 2024-06-15 \
  --limit 100 | \
  jq -r '.[] | select(.activityType.typeKey == "running") | .activityId' | \
  while read id; do
    gccli activity download "$id" --format gpx --output "run_${id}.gpx"
  done

Daily health dashboard

Pull today's key metrics into a JSON summary.

gccli --json health summary | jq '{
  steps: .totalSteps,
  calories: .totalKilocalories,
  distance_km: (.totalDistanceMeters / 1000),
  active_minutes: .moderateIntensityMinutes + .vigorousIntensityMinutes
}'

Track weight over time

Export weigh-in data as tab-separated values.

gccli --json body weigh-ins \
  --start 2024-01-01 --end 2024-06-30 | \
  jq -r '.dailyWeightSummaries[] | [.summaryDate, .weight.value] | @tsv'

Download the latest activity

One-liner to grab your most recent activity.

latest=$(gccli --json activities list --limit 1 | jq -r '.[0].activityId')
gccli activity download "$latest" --format fit

Create a structured running workout

Warmup, pace intervals, and cooldown.

gccli workouts create "Tempo 30min" --type run \
  --step "warmup:5m@pace:5:30-6:00" \
  --step "run:20m@pace:5:00-5:30" \
  --step "cooldown:5m"

Cycling with power targets

FTP interval workout for the bike.

gccli workouts create "FTP Intervals" --type bike \
  --step "warmup:10m" \
  --step "run:5m@power:250-280" \
  --step "recovery:3m" \
  --step "run:5m@power:250-280" \
  --step "cooldown:10m"

Architecture

Clean layered design with function-variable DI and context-based injection.

cmd/gccli/main.go → internal/cmd/ → internal/garminapi/ → internal/garminauth/

internal/cmd/

Kong-based CLI commands. Each command is a struct with Run(g *Globals) error.

internal/garminapi/

HTTP client returning json.RawMessage. RetryTransport.

internal/garminauth/

SSO auth: browser + headless login, DI OAuth exchange, MFA.

internal/secrets/

OS keyring abstraction. macOS Keychain, Linux Secret Service, file fallback.

internal/config/

Config file paths and environment variable overrides.

internal/outfmt/

Output formatting: JSON, Table, and Plain/TSV modes via context.

internal/ui/

Terminal UI with colors and prompts via termenv.

internal/fit/

FIT file binary encoding for weight and body composition uploads.
